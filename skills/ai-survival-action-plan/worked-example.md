# Worked synthetic example

All people, figures and events below are invented teaching inputs. This is an authored expected response, not a live model trial.

Synthetic input: An adult receives a voice message claiming a relative needs an urgent transfer. The voice sounds familiar. No payment has been made. The person has a previously saved number for the relative.

Plan: Pause the payment. Do not follow the message’s payment link or call its supplied number. Contact the relative through the independently saved channel and ask about the request. If contact fails or the story remains inconsistent, keep the payment paused and seek another trusted route. A familiar voice is not sufficient evidence.

Seven-day preparation: The adult writes a household verification procedure using roles rather than names, stores trusted contact routes privately, and rehearses one invented request with a consenting adult. Completion check: the participant can state the pause-and-verify steps without opening the suspicious link. Record only “completed / needs practice”, not a deception-detection percentage.

Remaining uncertainty: a saved account or device can be compromised. Passing a rehearsal does not prove a real future request will be detected. No real contact, financial transaction or security change is part of this example.
